# Workforce Management System

This project is developed as part of the Capgemini capstone project.

## Tech Stack

- ASP.NET Core Web API (.NET 8.0.421)
- Angular 21.2.12
- SQL Server
- Entity Framework Core Code First
- JWT Authentication
- GitHub
- Azure DevOps

## Main Modules

- Employee Management
- Department Management
- Attendance Management
- Leave Management
- Project Management
- Dashboard
- Reports
